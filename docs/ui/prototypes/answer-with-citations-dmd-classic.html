For trough opto failures on Bond Premium↗, the canonical service procedure comes from Service Bulletin SB-243↗. The most common failure mode is a hard fault on boot when the optos report inconsistent state — typically caused by a faulty opto board rather than the optos themselves.1

Before replacing the board, run the switch matrix test from the operator menu to confirm the symptom matches. If the test passes cleanly but ball-search behavior persists, the trough opto board (assembly 520-5246-00) is the likely culprit. Stern's operations manual covers the replacement procedure step-by-step including connector identification.2
