# PinballWizard UI Revamp (#343) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the MudBlazor CSS gap so all themes visually control MudBlazor components; add the Paper light palette as the new default; fix the Status page CSS bug; polish BrandFooter; add contract tests for all new behavior.

**Architecture:** The primary gap-fix mechanism is CSS custom property overrides — each `html.theme-<name>` block in `app.css` adds `--mud-palette-*` overrides that MudBlazor components read directly. `PinballTheme.CreatePaper()` provides the C# MudTheme object for server-side rendering and contract tests. Shape (2px radius) and zero elevation are added to all themes via `LayoutProperties` and `Shadows` on the MudTheme object.

**Tech Stack:** .NET 10 / Blazor Server / MudBlazor 9 strict (ADR-0008) / CSS custom properties / xunit contract tests.

**Spec:** `docs/superpowers/specs/2026-06-29-ui-revamp-design.md`
